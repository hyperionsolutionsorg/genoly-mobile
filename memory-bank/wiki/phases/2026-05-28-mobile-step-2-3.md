## Decisions

Five sub-decisions from Step 2+3's brief, recorded so future agents understand the path taken:

1. **Form library**: `react-hook-form@^7` + `zod@^3` + `@hookform/resolvers/zod`. Inputs wrapped in `<Controller>` — explicit ban on bare `setValue` (caused the first review-cycle bug).
2. **Email validation**: `z.string().email()`, RFC-permissive. Server re-validates.
3. **Password min length on client**: 8 chars (matches web signup policy). Server enforces real complexity.
4. **Forgot-password target**: `Alert.alert("Visit genoly.org from your browser to reset your password.")`. Web app owns the OTP-reset flow; mobile deep-linking deferred.
5. **Cold-start UX**: splash-screen stays mounted (`preventAutoHideAsync` + `hideAsync` on fonts loaded); component returns `null` while `authChecked` is false. The local token check is sub-50ms in practice so no separate spinner needed.
6. **Existing `(tabs)` scaffold**: left as-is per Decision 6. Auth gate redirects authenticated users INTO the 4-tab placeholder scaffold; tabs themselves remain the placeholder screens shipped at Phase 0. Real tab content lands in Step 5+ (dashboard, friends, leaderboard, settings).

## Review-cycle history (worth recording)

This step took **four review iterations** instead of the typical one to land, and the lessons are important enough to capture for future briefs:

- **Round 1 (Gemini Flash Low, Antigravity):** Shipped the structure correctly but had 5 critical bugs — form inputs not wired through `Controller` (so submit values were stale), auth gate called the stubbed `apiClient.getSession()` instead of `tokenStore.getToken()` (so every cold start redirected to login), `device.platform: 'mobile'` was an invented enum value, missing Rule #0 cascade, branch never pushed.
- **Round 2 (Gemini Flash Low):** Fixed the Controller wiring, switched to `tokenStore`, used `Platform.OS`. Introduced a NEW regression — `mapLoginError` used invented codes (`invalid_credentials`, `too_many_requests`) that don't exist in `ApiErrorCode`. Still no cascade. Still no commits. Antigravity claimed cascade was done; `git status` showed otherwise.
- **Round 3 (GPT-OSS 120B medium):** Fixed the error codes. Introduced ANOTHER regression — `(router as any).replace(...)` to silence tsc instead of typing the route. Still no `isExpired()` check. Still no cascade. Still no commits.
- **Round 4 (Claude takeover):** Replaced `(router as any)` with `LOGIN_ROUTE = '/(auth)/login' as unknown as Href` (narrow cast on the route string, preserves router-object typing). Added `tokenStore.isExpired()` to the auth check. Wrote 4-case `auth-gate.test.tsx` with proper module-scope `mockReplace` pattern. Wrote this phase page. Updated 6 state files.

**Lesson saved as memory:** Antigravity, regardless of underlying model, tends to chip away at review notes one item at a time and re-introduce regressions on other items in the process. Future handoffs to Antigravity should be smaller in scope OR pre-decompose into smaller PRs.
